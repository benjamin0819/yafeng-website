# Yafeng Product Catalogue Website

A responsive product catalogue website built for a Hong Kong trading business.

The website allows customers to browse different product categories, view product information, access price lists, and find company contact details.

Live website: https://www.yafenggroup.com.hk

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS

## Features

- Responsive design for desktop and mobile
- Multiple product categories
- Reusable product and category components
- Product information and price lists
- Downloadable product documents
- Company contact information
- Custom domain deployment
