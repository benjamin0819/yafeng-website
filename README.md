# 雅楓網站本地版本

這是一個 Next.js + TypeScript + Tailwind CSS 的本地可運行網站原型。

## 本地運行

1. 安裝 Node.js 18 或以上版本
2. 打開 Terminal / PowerShell
3. 進入專案資料夾

```bash
cd yafeng-website-local
npm install
npm run dev
```

然後打開：

```text
http://localhost:3000
```

## 現有功能

- 首頁 Hero 主打商品輪播
- 三大分類入口：餐飲糧油雜貨 / 清潔用品 / 紙巾類
- 六張主打商品展示
- 產品目錄篩選
- 紙巾六個子分類
- 獲取報價表單 UI
- 桌面端與手機端響應式布局
